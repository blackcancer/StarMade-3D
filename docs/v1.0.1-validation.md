## Scope and limits

The Display pass includes external native font/background resources, all six
face frames, style aliases, saved orientation-bearing keys, nested entity texts,
password suppression, depth testing and text distance. Calculated values are
provided by the host, independently per entity; the library does not simulate
reactors, shields or game networking. Native variable collisions and browser
font-metric differences are documented in `display-module.md`.

GPU checks establish rendering and update regressions, not pixel-identical
StarMade-client output or a GPU frame-rate guarantee. Native copyrighted assets
are absent from the release package. The npm-compatible tarball is distributed
through GitHub Releases, as in 1.0.0.
