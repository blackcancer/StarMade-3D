## Scope and limits

Display coverage includes cascading segments, native font sizes and outlines,
bounded offsets, text rotation, five backgrounds, external scanline animation,
all six face frames, saved text keys, depth testing, 500-unit text distance and
entity-scoped substitutions. Gameplay commands and simulation remain host-owned.
Browser font metrics and deliberate variable-refresh adaptations are documented.

The shared shader adapter supports the updated native cube directives with the
existing material sheet slots 0, 1, 2, 3 and 7. GPU regression checks do not claim
pixel-identical StarMade-client output or guaranteed GPU frame rates.

Native copyrighted assets are absent from the package. The npm-compatible tarball
is distributed through GitHub Releases, following the previous releases.
